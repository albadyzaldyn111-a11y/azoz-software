# Azoz Software

منصة ويب عربية لإدارة وكالة تطوير برمجيات، مبنية تدريجيًا لتبقى متوافقة مع استضافة PHP/MySQL تقليدية.

## الحالة الحالية

**المرحلة الأولى قيد التنفيذ:** تم إنشاء مخطط قاعدة البيانات، إعدادات البيئة، طبقة PDO، الجلسات، CSRF، المصادقة الأساسية، وصفحات البداية وتسجيل الدخول والخروج. لم تكتمل بعد إدارة التسجيل والتحقق من البريد وإعداد المدير الأول وبقية الوحدات.

## التشغيل المحلي

1. انسخ `.env.example` إلى `.env` واضبط الاتصال.
2. استورد `database/schema.sql` إلى MySQL/MariaDB.
3. شغل `php -S 127.0.0.1:8080 -t public`.
4. افتح `http://127.0.0.1:8080/`.

## التقنية

PHP 8.x، PDO، MySQL/MariaDB، HTML5، CSS3، وVanilla JavaScript. الواجهة العربية تستخدم RTL، وتبقى ملفات التطبيق والإعدادات خارج `public/` في البنية المقترحة.
