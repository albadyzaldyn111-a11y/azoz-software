# Azoz Software

منصة ويب عربية لإدارة وكالة تطوير برمجيات، مبنية تدريجيًا لتبقى متوافقة مع استضافة PHP/MySQL تقليدية.

## الحالة الحالية

**الإصدار القابل للنشر:** يتضمن الأساس الآمن، التهيئة لمرة واحدة، تسجيل العملاء والتحقق، طلبات المشاريع، عروض الأسعار وقبولها، المشاريع والأعضاء والمهام والمراجعات، المراسلات، الملفات الخاصة، التسليمات، المالية، المستخدمين، ودعوات المطورين.

يحتاج البريد في الاستضافة إلى SMTP خارجي. عند غياب SMTP، تُسجل روابط التحقق والدعوات في `storage/logs/mail.log` للاختبار المحلي فقط.

## التشغيل المحلي

1. انسخ `.env.example` إلى `.env` واضبط الاتصال.
2. استورد `database/schema.sql` إلى MySQL/MariaDB.
3. شغل `php -S 127.0.0.1:8080 -t public`.
4. افتح `http://127.0.0.1:8080/`.

## التقنية

PHP 8.x، PDO، MySQL/MariaDB، HTML5، CSS3، وVanilla JavaScript. الواجهة العربية تستخدم RTL، وتبقى ملفات التطبيق والإعدادات خارج `public/` في البنية المقترحة.
